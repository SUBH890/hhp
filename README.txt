IMVU BLACK MARKET - HTML/CSS starter

FILES
- index.html: responsive homepage layout and embedded CSS
- assets/: cropped image assets taken from the reference screenshot

HOSTINGER WORDPRESS INSTALL
1. Install WordPress and the WooCommerce plugin.
2. For a quick visual preview, upload the bmvu_site folder to a web host or open index.html locally.
3. For WordPress, create a page and use a Custom HTML block for the page markup. Move the CSS inside the <style> tag to Appearance > Customize > Additional CSS (or your theme's custom CSS area).
4. Upload the assets folder to WordPress Media Library and update the image paths in the HTML to their uploaded URLs.
5. Replace the demo product cards with WooCommerce product blocks/shortcodes. Use WooCommerce for real cart, checkout, stock, payment methods, order emails and customer accounts.

IMPORTANT
This is a static HTML/CSS visual recreation of the homepage. Product images are crops from the supplied screenshot, not original source files. Cart buttons, currency selector, live chat, and checkout/payment are visual placeholders; they are not connected to WooCommerce or a payment provider. Product detail, cart, and checkout pages need to be wired to WooCommerce for real transactions.
